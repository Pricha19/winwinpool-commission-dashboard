# WinWinPool Commission Dashboard

เครื่องมือเว็บสำหรับคำนวณค่าคอมมิชชั่นฝ่ายขาย แยกตามหมวดสินค้า **นำเข้าเอง** / **ในประเทศ** / **บริการ**
แทนไฟล์ Excel เดิม — deploy เองบน Netlify แบบสแตนด์อโลน

## โครงสร้างโปรเจกต์
```
/
├─ index.html              ← หน้าเว็บทั้งหมด (โหลด SheetJS จาก cdnjs)
├─ app.js                  ← ตรรกะทั้งหมด: parse Excel, คำนวณคอมมิชชั่น, เรียก API, render UI
├─ netlify.toml             ← ตั้งค่า build/functions/redirects
├─ package.json             ← dependency เดียวคือ @netlify/blobs
└─ netlify/functions/
   ├─ index.mts             ← GET /api/index
   ├─ months.mts            ← GET /api/months
   └─ upload.mts            ← POST /api/upload
```

## วิธี deploy

1. **ผ่าน Git (แนะนำ):** push โฟลเดอร์นี้เป็น repo แล้วเชื่อมกับ Netlify (New site from Git) — Netlify จะ build/deploy อัตโนมัติทุกครั้งที่ push
2. **หรือผ่าน Netlify CLI:**
   ```bash
   npm install
   npx netlify deploy --prod
   ```
3. Netlify Blobs ใช้งานได้ทันทีไม่ต้องตั้งค่า credential เพิ่ม (ทั้งตอนรันจริงบน Netlify และตอนรัน `netlify dev` ในเครื่อง)

## จำกัดการเข้าถึง (รหัสผ่านเดียวทั้งบริษัท)

ไปที่ **Site settings → Visitor access → Password protection** ในหน้า Netlify แล้วตั้งรหัสผ่านเดียว —
ครอบคลุมทั้งหน้าเว็บ static และ endpoint `/api/*` โดยอัตโนมัติ ไม่ต้องเขียนโค้ดตรวจสอบสิทธิ์เพิ่มในแอป
(ต้องใช้ Netlify plan ที่รองรับฟีเจอร์นี้)

## ตรรกะทางธุรกิจ (สรุป)

- **จัดหมวดสินค้าจากรหัสสินค้า:** `SV-` นำหน้า → บริการ, มีคำว่า `-WW-`/`-WP-`/`-LS-`/`-PT-`/`-ADS-` → นำเข้าเอง, อื่นๆ → ในประเทศ (ตรวจ `SV-` ก่อนเสมอ)
- **จัดสาขาจากตัวอักษรแรกของรหัสฝ่ายขาย:** `B`→สำนักงานใหญ่, `H`→หัวหิน, `P`→พัทยา
- **นับเฉพาะรายการสถานะ "ตรงกัน (ยืนยันแล้ว)"** เข้ายอดขาย/คอมมิชชั่น (เช็คใบยกเลิก → Draft → ไม่พบใน TAX → ฐานภาษีไม่ตรง → ตรงกัน ตามลำดับ)
- **DEP (มัดจำบางส่วน):** ค่าแรง/บริการ (`SV-`) ถือว่าจ่ายก่อนเสมอ ส่วนที่เหลือเฉลี่ยเท่าๆ กันในบรรดาสินค้าที่เหลือ — ผลรวม netSales ของทั้งใบเท่ากับฐานภาษีที่ตรงกันเป๊ะเสมอ
- **บั๊ก พ.ศ./ค.ศ.:** ปีที่เกิน 2100 ถือเป็น พ.ศ. ที่หลุดมา ต้องลบ 543

รายละเอียดทั้งหมดอยู่ในคอมเมนต์ของ `app.js` และตรงกับสเปกต้นฉบับที่ได้รับทุกประการ
ตรวจสอบแล้วกับข้อมูลจริงหนึ่งปี (INV 49,390 รายการ / DEP 3,530 รายการ / TAX 22,312 ใบ) —
ยอดรวมสอดคล้องกัน 100% ระหว่างวิธีคำนวณรวมทีเดียวกับวิธีแยกเดือนแล้วบวกกลับ (conservation test)

## ก่อน deploy จริง ควรตรวจสอบ

- [ ] เทียบยอดรวม/สถานะกับสูตร Excel เดิมทีละยอด
- [ ] รัน `netlify dev` ทดสอบ Function ทั้ง 3 ตัวในเครื่องก่อน อัปโหลดไฟล์ตัวอย่างแล้วเช็คว่า blob ถูกเขียนถูกต้อง
- [ ] ทดสอบตัวกรองช่วงเวลา + พนักงาน สลับไปมา
- [ ] เปิด 2 แท็บ อัปโหลดจากแท็บหนึ่ง เช็คว่าอีกแท็บเห็นข้อมูลใหม่ภายในรอบ polling (60 วินาที) หรือหลังรีเฟรช
- [ ] ทดสอบว่า Password Protection บังคับใช้จริงทั้งหน้าเว็บและ `/api/*`
- [ ] ทดสอบโหมดสว่าง/มืด และหน้าจอมือถือ (~390px)
